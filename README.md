# Swell Line

Low-poly three.js surf game set at Koshigoe beach, Kamakura (35.306°N 139.497°E).

- Pick a board (performance, fish, mid-length, longboard) in a 3D preview with top and side views
- Randomly generated sets: size, peak and peel direction change every wave
- Paddle, steer left/right, regular or goofy stance
- Simulated tide and wind that change the waves while you surf
- Generative radio: ambient piano, lo-fi, 8-bit

Single static file: `index.html`. No build step.

## Deploy on Render

New → Static Site → this repo. Build command: empty. Publish directory: `.`

## Controls

Space paddle / pump · ← → steer · + − zoom · C camera · Esc pause
